## [1.0.0] — 2026-10-22

Первый релиз для Windows: порт RadioMac на .NET 10 / Avalonia / libVLC.

### Добавлено

- Трей-агент: левый клик — мини-плеер, правый — меню (играть/пауза, стоп, таймер сна,
  история, настройки, обновления, выход), тултип со станцией и треком.
- Безрамочное окно 780×660 с редакционной монохромной вёрсткой; Esc/× скрывают окно,
  эфир продолжается.
- Навигация по жанрам, избранному и группам, обложка текущей станции/трека.
- Таблица станций: поиск, счётчик, избранное, меню ⋮, контекстное меню, удаление,
  перетаскивание порядка в режиме «Все».
- 47 встроенных станций, каталог перенесён из macOS-версии; добавление и правка своих.
- Воспроизведение HLS/AAC/MP3/ICY через libVLC, пауза, стоп, предыдущая/следующая,
  громкость, LIVE/OFF AIR.
- Автопереподключение с backoff 1/2/5/10 с и кнопкой «Повторить».
- Метаданные: ICY side-channel, Icecast, SomaFM, Radio Paradise, обложки iTunes.
- Логотипы станций: Radio Browser → сайт из ICY → favicon, с дисковым кэшем.
- 10-полосный эквалайзер с пресетами и своей кривой, применяется без перезапуска.
- Таймер сна с затуханием, будильник с днями недели и нарастанием громкости.
- История треков (100 записей), поиск, копирование и очистка.
- Глобальные горячие клавиши и автозапуск при входе в Windows.
- Radio Browser: поиск, превью, добавление без дубликатов.
- Импорт/экспорт JSON, M3U и OPML с режимами «Добавить/Заменить».
- Настройки станции: смещение громкости, EQ-пресет, автозапуск.
- Last.fm: opt-in теперь-играет и скробблинг после 4 минут.
- Локальная диагностика: opt-in журнал, обнаружение аварийных завершений, копирование.
- Проверка обновлений через GitHub Releases.
- Русский и английский интерфейс, светлая/тёмная/системная тема.
- Установщик Inno Setup и портативный ZIP, self-contained публикация.
- CI, релизный workflow, CodeQL, проверка зависимостей, headless-скриншоты.
