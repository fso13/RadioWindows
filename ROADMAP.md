# Планы

## Ближайшее

- **Медиа-клавиши и SMTC**: интеграция с System Media Transport Controls, чтобы
  играть/пауза работали с клавиатуры и из центра уведомлений Windows.
- **Подпись установщика**: Authenticode-сертификат и автоматическая подпись в release.yml.
- **Обновление «в одно нажатие»**: скачивание и запуск установщика из приложения
  с проверкой SHA-256.

## Дальше

- **Экспорт состояния в Windows-виджет**: мини-приложение для панели виджетов Windows 11.
- **Несколько профилей библиотек** и синхронизация через папку пользователя.
- **Командная строка**: `radiowindows://play/<id>`, открытие станции из браузера.
- **Ночной режим**: автоматическое переключение темы по расписанию.
- **Тесты интерфейса**: скриншот-тесты с порогом различия для светлой и тёмной темы.
- **ARM64**: отдельная публикация `win-arm64` (libVLC уже поддерживает).

## Сделано
