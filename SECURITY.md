# Безопасность

## Поддерживаемые версии

| Версия | Поддержка |
| --- | --- |
| 1.x | да |

## Как сообщить об уязвимости

Не открывайте публичный issue для уязвимостей. Напишите на
[security@fso13.dev](mailto:security@fso13.dev) или через
[GitHub Security Advisories](https://github.com/fso13/RadioWindows/security/advisories/new).
Укажите версию, шаги воспроизведения и оценку влияния. Ответ — в течение 72 часов,
исправление и раскрытие — после выхода патча.

## Что делает приложение

- Не отправляет данные на серверы проекта: телеметрии и аналитики нет.
- Сеть используется только для потоков радио, обложек и метаданных, Radio Browser,
  Last.fm (если включён) и проверки обновлений GitHub.
- Локальный журнал выключен по умолчанию; URL в нём обрезаются до схемы и домена.
- Last.fm-сессия хранится в защищённом хранилище Windows (DPAPI) для текущего пользователя.
- Автозапуск — только раздел `Run` в `HKCU`, без служб и планировщика.
- Установщик ставится в профиль пользователя и не требует прав администратора.

## Зависимости

- `dotnet list package --vulnerable --include-transitive` в CI (`security.yml`);
- CodeQL для C# (`codeql.yml`);
- Dependency Review для pull request'ов;
- libVLC обновляется вместе с пакетом `VideoLAN.LibVLC.Windows`.

## Ограничения

- Приложение не подписано EV-сертификатом: SmartScreen может предупредить.
  Проверяйте SHA-256 по `SHA256SUMS.txt` из релиза.
- Сторонние потоки могут содержать нежелательный контент; приложение только проигрывает
  ссылку, которую добавил пользователь или Radio Browser.
